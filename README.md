# Note App

A modern and minimalistic note-taking Android application built using **Java**, **SQLite**, and **Fragments**.  
The app allows users to create, view, edit, and delete their notes with ease. Designed to be simple, elegant, and efficient.

## ✨ Features
- Add new notes with title and content
- Display notes in a scrollable grid
- Edit and delete existing notes
- SQLite database integration
- Search notes by title
- Bottom navigation bar with multiple views (coming soon)
- FloatingActionButton (FAB) for quick note entry

## 🔧 Technologies
- Java
- Android SDK
- SQLite (via SQLiteOpenHelper or Room)
- RecyclerView
- Fragments
- Material Design Components

## 📦 Status
In development – core features implemented, UI enhancements ongoing.
